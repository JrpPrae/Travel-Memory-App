# Travel Memory Pinboard

มินิมอลเว็บแอปปักหมุดความทรงจำนักเดินทาง นับจำนวนสถานที่ที่เคยไป 3 หมวด: จังหวัดในไทย, ป่าและอุทยานสำหรับสายเดินป่า, และประเทศทั่วโลก พร้อมระบบบันทึกภาพ โน๊ต วันที่ เช็กลิสต์ และแผนการเดินทาง

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`
